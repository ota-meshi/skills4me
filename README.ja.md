# skills4me

[English](README.md)

手元の Git チェックアウトにあるスキルを Claude Code と Codex のユーザーレベルで使うための CLI です。未管理のスキルを、選んだチェックアウトに取り込むこともできます。

以下のコマンドには Node.js 22 以降と `skills4me` 0.1.0 以降が必要です。対話端末で `npx skills4me` を実行するとコマンドを選べます。

## チェックアウトのスキルを使う

スキルごとに `skills/<名前>/` を作り、`SKILL.md` と関連ファイルを置きます。スキルが一つだけなら `skills/SKILL.md` に直接置くこともできます。チェックアウト内で実行します。

```sh
npx skills4me link
```

検出したすべてのエージェントにスキルをリンクします。使いたいチェックアウトごとに実行し、スキルを追加・改名・削除したら再実行します。リンク先からの編集はチェックアウトの原本に反映されます。同名の既存スキルはそのまま残り、競合が表示されます。

別の場所からは `npx skills4me link <ディレクトリ>` でチェックアウトを指定できます。チェックアウトの外でパスを省略すると、対話端末ではディレクトリを選べます。

## スキルを Git 管理に取り込む

先に取り込み候補を確認するには `npx skills4me detect` を使います。リンクと、`skills` CLI や `openskills` の管理記録に載っているスキルは候補から除かれます。

取り込み先のチェックアウト内で、対話端末から実行してスキルを選びます。

```sh
npx skills4me adopt
```

スキル一式はチェックアウトの `skills/` に移り、元の場所にはリンクが残ります。取り込んだファイルは普段どおり Git でコミットできます。別の場所から実行する場合は `--to <ディレクトリ>` で取り込み先を指定できます。

ヘルプは `npx skills4me --help` で表示できます。
