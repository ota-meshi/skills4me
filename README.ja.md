# skills4me

[English](README.md)

Claude Code、Codex、Cursor、Gemini CLI などのコーディングエージェントで、複数のプロジェクトをまたいで使うユーザーレベルの Agent Skills を管理する CLI です。

Node.js 22 以降が必要です。

対話端末で `npx skills4me` を実行すると、コマンドを選べます。

## チェックアウトのスキルを使う

事前登録や中央管理用のディレクトリなしで、個人用と仕事用など複数の Git チェックアウトを併用できます。

スキルごとに `skills/<名前>/` を作り、`SKILL.md` と関連ファイルを置きます。スキルが一つだけなら `skills/SKILL.md` に直接置くこともできます。チェックアウト内で実行します。

```sh
npx skills4me link
```

選んだエージェントのユーザーレベルのスキルディレクトリにリンクを作ります。対話端末では対応するすべてのエージェントが表示され、検出したエージェントが最初から選ばれています。対話端末でなければ、検出したすべてのエージェントにリンクします。使いたいチェックアウトごとに実行し、スキルを追加・改名・削除したら再実行します。リンク先からの編集はチェックアウトの原本に反映されます。同名の既存スキルはそのまま残り、競合が表示されます。

エージェントの選択画面を省くには、`npx skills4me link --agent claude-code --agent cursor` のように指定します。自動検出されなかったエージェントも指定できます。`--agent` に指定できる名前の一覧は `npx skills4me link --help` で確認できます。

別の場所からは `npx skills4me link <ディレクトリ>` でチェックアウトを指定できます。チェックアウトの外でパスを省略すると、対話端末ではディレクトリを選べます。

## スキルを Git 管理に取り込む

`npx skills4me detect` で取り込み候補を確認できます。リンクは候補に含まれません。対応する記録がない外部スキルも候補に出る場合があるため、取り込むスキルは一覧を確認して選んでください。

取り込み先のチェックアウト内で、対話端末から実行してスキルを選びます。

```sh
npx skills4me adopt
```

スキル一式はチェックアウトの `skills/` に移り、元の場所にはリンクが残ります。取り込んだファイルは普段どおり Git でコミットできます。別の場所から実行する場合は `--to <ディレクトリ>` で取り込み先を指定できます。

`detect` と `adopt` でも `--agent` を指定でき、そのエージェントのスキルディレクトリだけを探します。

ヘルプは `npx skills4me --help` で表示できます。
